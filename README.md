# Basic Calculator

A simple beginner-friendly Python calculator that performs basic arithmetic operations based on the user's choice.

## About the Project

The program takes two numbers from the user and asks which operation they want to perform.

The calculator supports:

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)

The program uses `if`, `elif`, and `else` statements to determine which calculation should be performed.

## Concepts Used

This project was created to practice basic Python concepts, including:

* `input()` for taking user input
* Variables
* Type conversion using `int()` / `float()`
* `if`, `elif`, and `else` statements
* Arithmetic operators
* Basic program logic

## Example

```text
Enter first number: 20
Enter second number: 5

Enter operation (+, -, *, /): *

Result: 100
```

## How to Run

Make sure Python is installed on your computer.

Run the program from the terminal:

```bash
python calculator.py
```

## Purpose

This is a simple practice project created while learning Python fundamentals and conditional statements.
